🧠 Featured Project — PrediCare TPA
🏥 Medical Fraud Detection & AI-Powered RAG Assistant

Role: Machine Learning Pipeline, Backend API & RAG Integration
Context: AI Cohort Capstone Project — Ingedata / ODC
Timeline: October 2026

PrediCare TPA is an AI-driven project designed to support medical fraud detection and provide document-based assistance through a Retrieval-Augmented Generation system.

🔍 Machine Learning Pipeline
Prepared and analyzed 24 months of synthetic historical data using SQL and Pandas.
Developed and compared classification models using XGBoost and LightGBM.
Addressed class imbalance using SMOTE after the train/test split to prevent data leakage.
Evaluated models using recall, F1-score, and Precision-Recall AUC.
Applied threshold optimization to prioritize fraud detection.
Integrated SHAP to explain individual predictions and support alert interpretation.
⚙️ Backend & MLOps
Built a prediction API using FastAPI.
Integrated PostgreSQL and pgvector for structured data and vector storage.
Containerized services using Docker.
Implemented health checks and monitoring indicators for API performance.
Contributed to automated alert workflows using n8n.
🤖 RAG Assistant
Developed a document retrieval workflow for PDF contracts and business information.
Integrated LangChain, pgvector, and a local LLM through Ollama.
Designed responses with supporting source references to improve traceability.
